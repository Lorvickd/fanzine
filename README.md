# fanzine
Fanzine web hecho con HTML y CSS para la entrega final de Taller Multimedia 1.
- Repositorio: https://github.com/Lorvickd/fanzine
- Página pública: https://lorvickd.github.io/fanzine/
## Colores y estética

La página usa rojo y negro sobre un fondo de papel arrugado. Su estética amateur, inspirada en las páginas personales de los 2000, imita las ventanas de Windows 98 e Internet Explorer: bordes en relieve, barras de título rojas y letras como Courier New, Times New Roman e Impact.

## Estructura

- **Ventana principal:** el logo VISTAZO junto a un televisor con estática, el lema y una alerta animada.
- **Historias:** cada una tiene un título en una cinta roja en movimiento, una imagen y el texto al lado.
- **Columna lateral:** botones para saltar a cada historia y una caja de música con la canción de la edición.

## Idea

Quise que la revista se sintiera como abrir una página olvidada en un computador viejo: algo hecho a mano, un poco incómodo y nervioso, como sus personajes. Por eso usé animaciones de **Animate.css** como el parpadeo de la alerta, los textos que se mueven y la estática del televisor.
